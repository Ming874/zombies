# 聖心醫院 · 殭屍生存

網頁 3D 第一人稱殭屍生存射擊遊戲(Three.js r186 + Vite 8)。
午夜之後的聖心醫院:地下納骨堂、挑高大廳、重複得令人迷失的病房、精神科隔離區與醫院外的停車場與墓園。撐過一波又一波的屍潮,在回合之間到 1F 便利商店改成的商店補給、升級武器。支援 2–4 人合作生存與 2–8 人對戰死鬥連線。

## 特色

- **多樓層醫院**:B1 / 1F / 2F / 3F 加上戶外區域,約 75 個風格不同的區域;燈光、霧與環境音依區域變化,有腳本化的心理驚嚇事件。
- **十一種活屍**:行屍、狂奔者(飛撲)、爬行者、膿腫者(吐酸、死亡爆炸)、巨屍(衝鋒、穿護甲),第 4~10 波依序加入尖叫者(召喚、暈眩)、手術者、束縛病患(衝撞)、焦屍、潛行者(爬天花板、怕手電筒)、清理隊員(防護衣);另有追逐戰專用、打不死的追獵者。新類型偏好在對應的區域出生(手術室、鍋爐房、太平間…)。可斷頭斷肢,死後變成物理布娃娃。
- **六把武器**:手槍、左輪、霰彈槍、AK-47、M4A1、巴雷特(全螢幕狙擊鏡);另有手榴彈與小刀。開鏡、後座圖樣、穿透與距離衰減。
- **回合制難度曲線**:每 5 波首領(巨屍);特殊的夜:第 6 波廣播(出生點偏向大廳的喇叭)、**第 8 波停電**(那層樓只剩緊急照明、潛行者變多)、之後警鈴 / 廣播 / 狂奔 / 膿毒輪流;第 5 波起血量逐步增加。一波裡有高峰與山谷(張力太高時暫停出怪 8~15 秒),站在同一個點太久,牠們會從身後來(先有聲音)。
- **四段難度**(主選單):阿嬤會一直叫你 / 阿嬤叫你三遍 / 阿嬤叫你一遍 / 無人叫你——倒下後能醒來的次數,加上數量、血量、速度、傷害、節奏的倍率;合作時數量依人數增加。
- **噪音**:開槍(巴雷特最大聲、手槍最小)、重落地、甩門、爆炸會留下噪音,活屍比較會從吵的地方附近出來(追擊不變)。
- **商店**:武器、各武器彈藥(買不起補滿時可只買幾個彈匣)、四種改裝(傷害 I–III、彈匣 I–II、換彈 I–II、穩定 I–II,價格逐級遞增)、防彈背心與修補、手榴彈、醫療包、急救處置。數值條會與手上的武器比較。
- **掉落物**:殭屍會掉落彈匣與醫療包(偶爾手榴彈;膿腫者、焦屍、清理隊員、巨屍比較常掉),會發光、靠近自動吸過來,約 40 秒後閃爍消失;彈藥或生命不足時掉落率提高。
- **補給櫃**:彈藥櫃只補手上那把槍;每個櫃子每一波一次、一晚最多 3 次,用完要去別的樓層找。
- **計分與紀錄**:爆頭、近戰、連殺倍率、無傷清場;死亡結算顯示各類型擊殺、爆頭率、命中率、最高連殺,並保存本機最佳紀錄。
- **新手提示**:依情境出現一次的提示(按 T 關閉,可在設定重設)。
- **設定**:滑鼠靈敏度、反轉 Y 軸、FOV(開鏡與狙擊鏡跟著縮放)、主音量/音樂/音效、畫質預設(依顯示卡自動挑選)、陰影、光暈、動態解析度。
- **效能**:Web Worker 建模與貼圖、Rapier 物理(WASM)、固定光源池、動態解析度;按 F3 看效能面板。可安裝為 PWA。

### 控制面板(F8)

按 F8 開關;單人時遊戲暫停,多人時世界照常進行。斜線可省略,Tab 自動完成、↑↓ 叫出之前的指令、Esc 關閉。

| 指令 | 說明 |
|---|---|
| `/give <玩家> <物品> [數量]` | 給予物品。玩家可省略(= 自己) |
| `/list` | 玩家清單與編號 |
| `/help` | 指令與物品一覽 |
| `/clear` | 清除畫面 |

- 玩家:`me`(自己)、`@a`(所有人)、`/list` 裡的編號(多人時 = 座位 + 1)、或暱稱(打開頭幾個字即可)。
- 物品:`pistol` `revolver` `shotgun` `ak47` `m4a1` `barrett` `rpg`(武器,彈藥補滿並切過去)、`rocket`(RPG 火箭彈)、`ammo`(全部彈藥補滿)、`grenade`、`medkit`、`armor`(重型背心)、`coins`(金額,預設 1000)、`hp`(生命回滿)、`all`(全部)。也接受中文別名,例如 `火箭筒`、`手榴彈`、`金幣`。
- 例:`/give me rpg`、`/give rocket 5`、`/give 2 coins 500`、`/give @a grenade 3`。
- 多人模式只有房主能用 `/give`,可以給房間裡任何人(伺服器只轉發房主送的給予訊息)。

**RPG-7**(第 7 格,只能用 `/give` 取得,商店與對戰選槍不會出現):射出實體火箭,撞到牆、地板、殭屍就爆炸(爆心 320 傷害、半徑 6.5m,和手榴彈一樣會被牆擋住);單發,換彈 2.8 秒;離太近會炸到自己。

## 遊戲規則

- 每回合清光殭屍後,地上的金幣(以及用得到的掉落物)會飛向你,並發放清場獎勵(20 + 10 × 回合);整回合沒受傷再加「毫髮無傷」獎勵。
- 回合間休息 30 秒(首領回合前 40 秒),商店捲門拉起;**單人模式購物時遊戲暫停**。每一波開始每把武器自動補 1 個彈匣,一波結束回復 20 生命。
- 金幣:行屍 6、狂奔者 8、爬行者 7、膿腫者 12、巨屍 45;爆頭 +50%、近戰擊殺 +100%;5、8、12、16、20 連殺另有金幣獎勵。
- 武器價格:左輪 120、霰彈槍 180、AK-47 300、M4A1 450、巴雷特 1,350。站樁 bot(M4、1/3 打頭)實測累計收入第 1~8 波約 90 / 240 / 400 / 640 / 950 / 1,330 / 1,760 / 2,300;全部存起來的話第 2 波後買得起左輪或霰彈槍、第 3 波 AK-47、第 4 波 M4A1、第 7 波左右巴雷特(先買 M4 就要到第 8~9 波)。
- 數值集中在:`src/weapons/weapon.js`(武器)、`src/game/waves.js`(回合數量/組成/血量倍率/節奏、計分、獎勵)、`src/shop.js`(商品與價格)、`src/pickups.js`(掉落率)、`src/zombies/types.js`(殭屍基本數值)。

## 執行與建置

需要 Node.js 20 以上。

```bash
npm install
npm run dev          # 開發伺服器 http://localhost:5173(單人可直接玩)
npm run server       # 另開一個終端機:多人連線伺服器(預設 8787),開發伺服器會把 /ws 轉過去
npm run build        # 輸出到 dist/
npm start            # 正式環境:node server/index.js 同時提供 dist/ 靜態檔與 /ws(使用 PORT 環境變數)
```

- 正式伺服器會送出跨來源隔離標頭(COOP / COEP),讓物理 Worker 可以使用 SharedArrayBuffer;開發伺服器(vite.config.js)也一樣。
- 健康檢查:`/healthz`;公開房間列表:`/api/rooms`。登入與存檔見下面的〈登入與存檔點〉。
- 網址參數(除錯用):`?physics=off|main|worker`、`?blockout`(灰盒場景)、`?room=代碼`(直接加入房間)。

### 效能:遊戲中偶爾整個畫面停 1~3 秒

Windows 版 Chrome 預設用 ANGLE 的 Direct3D 11 後端:畫面上第一次出現某種繪製組合時,會現場把 shader 編譯成 D3D 版本。舊款或時脈低的 CPU(例如 Xeon E5 v3)一次要 0.5~3 秒,期間整個畫面停住,而且每次開遊戲都可能再發生(F3 面板的「卡頓 >50ms」會一直增加)。
改用 Vulkan 後端可以避開:在網址列打開 `chrome://flags/#use-angle`,把「Choose ANGLE graphics backend」改成 **Vulkan**,重新啟動 Chrome。
實測(Xeon E5-2678 v3 + RTX 3060):載入從約 44 秒降到約 22 秒,遊戲中的卡頓幾乎消失;平均幀率比 D3D11 低一點(混戰時約 34 對 41 FPS)。

HUD、字幕、提示等網頁元素刻意不用 CSS `filter` / `backdrop-filter` / `mask`(會在瀏覽器合成器每幀重新套用,並觸發上述的 shader 編譯);需要模糊、褪色的畫面效果請寫在 `src/game/post.js` 的 uniform。

### 部署(Zeabur)

`zbpack.json` 已設定 `build_command: npm run build`、`start_command: node server/index.js`;平台提供的 `PORT` 會自動使用。推送到追蹤的分支即會重新部署。

## 多人連線

主選單選「合作生存」或「對戰死鬥」進入大廳:設定暱稱、建立房間(公開或私人)、輸入 6 碼代碼加入,或從公開房間列表加入;房間內可以聊天、準備、由房主開始。邀請連結為 `?room=代碼`。

- **合作生存**(2–4 人):共用殭屍與回合;血量歸零先倒地 30 秒,隊友靠近按住 E 3 秒救起;全員倒地才結束。
- **對戰死鬥**(2–8 人):各自為戰,先到擊殺上限或時間到結束,可選擇加入零星殭屍騷擾。
- 由房主的瀏覽器模擬殭屍與回合,伺服器只負責房間與轉發;房主離線時自動轉移。

## 登入與存檔點

- **Google 登入**:主選單右上角「用 Google 登入」。走伺服器端的 OAuth 2.0 授權碼流程(整頁重新導向 + PKCE;頁面開了 COOP/COEP,不能用 Google 的按鈕或彈出視窗)。登入後頭像和名字顯示在主選單。
- **存檔點(單人)**:每一波打完、進入休息時自動存一份。主選單多一個「繼續(第 N 波之後・封院第 N 天)」,進去就停在那一次休息(商店開著),下一波是 N+1。按「新的一夜」會先問要不要覆蓋存檔點。沒有登入時存在這台電腦的瀏覽器(localStorage)。
- **雙人(合作)進度**:房間裡每個人都登入時,房主每次休息把共用的回合狀態存成隊伍存檔(key = 兩人的帳號 id 排序),每個人的裝備存在自己的帳號下。同樣的人再組隊,大廳會提示「繼續你們上次的進度」,房主按下去就照存檔恢復。
- 存了什麼:波數、難度、分數與金幣、武器/彈藥/改裝、護甲、手榴彈、醫療包、生命、目標進度與劇情旗標、道具、門鎖、筆記本這一局拿到的卡、207 的油量、封院天數、魂火。抽屜開關、地上的屍體、這一波的殭屍不存。

### 伺服器設定(環境變數)

| 變數 | 說明 |
|---|---|
| `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET` | Google Cloud Console 的 OAuth 用戶端(網頁應用程式)。沒設定時不顯示登入按鈕,`/api/me` 回 `{ enabled: false }`,遊戲照常可玩(存檔只在瀏覽器) |
| `PUBLIC_URL` | 選填。網站的正式網址(例 `https://zombies.zeabur.app`);不設定時依請求的 Host 與 `x-forwarded-proto` 組出重新導向 URI |
| `DATA_DIR` | 帳號、session、存檔的 JSON 檔放哪裡(預設 `<repo>/data`,已加進 .gitignore) |
| `AUTH_DEV` | 只給測試用:設成 `1` 才開放 `/auth/dev?name=xxx` 假登入。**正式環境不要設** |

Google Cloud Console:建立「OAuth 用戶端 ID」→ 應用程式類型選「網頁應用程式」→「已授權的重新導向 URI」填 `https://<你的網域>/auth/google/callback`(本機開發另外加 `http://localhost:5173/auth/google/callback` 或 `http://localhost:8787/auth/google/callback`)。

**Zeabur 一定要掛 Volume**:容器每次重新部署都是新的檔案系統。在服務的「Volumes」加一個掛載路徑(例如 `/data`),再把環境變數 `DATA_DIR` 設成同一個路徑;沒有掛的話,每次部署帳號與存檔都會消失。

存檔 API(都要登入):`GET/PUT/DELETE /api/save/<slot>`(每份 128 KB、每個帳號 10 份)、`GET/PUT /api/team/<房間代碼>`(隊伍存檔,房主寫)、`GET/PUT /api/team/<房間代碼>/gear`(自己的裝備)。寫檔先寫暫存檔再改名(不會寫壞),同一個檔案 1 秒內的變更合併成一次寫入。測試:`node --test server/test/auth.test.mjs server/test/saves.test.mjs`(假的 token 端點,不連 Google)。
